## 🎨 Дизайн и концепция
- **Стилистика:** Изысканная палитра в стиле аватарки и Instagram Stories студии — фарфоровый белый, мягкий пудрово-бежевый оттенок с акцентами теплого розового золота и мраморной акварели.
- **Типографика:** Высококонтрастные классические заголовки `Cormorant Garamond` и `Italiana`, акцентный рукописный курсив `Playfair Display`, чистый современный гротеск `Plus Jakarta Sans` для удобного чтения цен.
- **Интерактивный прайс-лист:** Все 48 услуг студии из актуальных прайсов (Волосы, Ногти, Ресницы, Брови, Депиляция/Шугаринг) с моментальным поиском и переключением вкладок.
- **Галерея работ с Lightbox:** Фотографии работ в высоком разрешении с модальным окном увеличения и быстрой кнопкой записи на конкретную процедуру.
- **Мягкий блок отзывов:** 3 ненавязчивых отзыва постоянных клиенток студии без перегрузки внимания.
- **Умные контакты:** Интеграция с карточкой 2ГИС, кнопка построения маршрута, часы работы и быстрый переход в WhatsApp с автозаполнением темы визита.
- **100% Mobile First:** Идеальная адаптивность для любых экранов (360px, 390px, 430px, планшеты и десктопы) без горизонтального скролла с плавающей кнопкой записи.
